# Security Policy · Sicherheit

**English** · [Deutsch](#deutsch)

## Supported versions

Only the latest release receives security fixes.

| Version | Supported |
|---|---|
| latest 0.x | ✅ |
| older | ❌ |

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Use GitHub's private reporting instead: **Security → Report a vulnerability** in this repository
(<https://github.com/t3chdock-labs/TillSplit/security/advisories/new>).

Please include the affected version, a description, steps to reproduce and – if possible – a suggested fix.
You will get a first answer within 7 days. Please give us reasonable time to release a fix before disclosing the issue.

Never send real API keys, passwords, receipts or backups with a report.

## Deutsch

### Unterstützte Versionen

Sicherheitskorrekturen gibt es nur für die jeweils neueste Version.

### Sicherheitslücke melden

Bitte **kein öffentliches Issue** für Sicherheitsprobleme anlegen, sondern die private Meldung von GitHub nutzen:
**Security → Report a vulnerability** (<https://github.com/t3chdock-labs/TillSplit/security/advisories/new>).

Bitte Version, Beschreibung, Schritte zum Nachstellen und wenn möglich einen Lösungsvorschlag angeben.
Eine erste Antwort kommt innerhalb von 7 Tagen. Bitte gib uns Zeit für eine Korrektur, bevor du die Lücke veröffentlichst.

Niemals echte API-Schlüssel, Passwörter, Bons oder Backups mitschicken.
